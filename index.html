Partie pratique

  1. Créer un dépôt Git (vraisemblablement sur GitHub)
    • Si vous n'avez pas de compte, il faudra vous en créer un
  2. Réaliser un premier commit avec un fichier README.md
  3. Créer un deuxième commit avec un second fichier (html, ...)
  4. Réaliser un troisième commit qui modifie le fichier README.md et supprime le fichier HTML

Tout doit être réalisé en ligne de commande.

Référence : cda-27-2-github

Pour vérifier, utilisez la commande suivante : git log --graph
